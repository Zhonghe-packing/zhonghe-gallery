# V11 更新说明

- 首页 Banner 改为左 / 中 / 右三段式背景。
- 电脑端三段独立显示，图片按比例裁切，不做横向变形。
- 手机端只显示中间 Banner，左右两段隐藏且强制不显示背景图。
- 后台可分别上传、更换、删除左侧背景、中间主背景、右侧背景。
- 兼容原有 hero 背景：如果数据库已有旧的 hero 图片，会自动作为中间主背景使用。
- 其他 V10 页面布局保持不变。

V12修正：三段Banner采用绝对定位，左侧背景固定在网页最左侧，中间主图居中段，右侧背景固定在网页最右侧；背景图按比例显示（auto 100%）不横向拉伸。手机端隐藏左右背景，只显示中间主图，并保持主文案可见。
